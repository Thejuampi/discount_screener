# Operational anti-patterns (ledger)

Failure modes that already bit this repo, with what broke and the fix. Read this file before a change that re-triggers the same failure shape. Green tests are evidence for the encoded properties, never the conclusion that all required properties were encoded.

**Rule:** when a new operational failure mode appears, add a row here (and a step to the manual procedures in `AGENTS.md` if it changes a standing gate) — do not leave it only in chat.

| Anti-pattern | What happened | Do instead |
| --- | --- | --- |
| “T looks good vs Street → ship” | Soft WACC / FCF run-rate changes broke other names (e.g. AMZN-class) | Multi-name baseline green **before** claiming done |
| “Typed/atomic/idempotent” asserted from local helpers | Each checkpoint was green while the write boundary, whole lifecycle, or semantic command still had bypasses | Apply [`analyst-method-lifecycle.md`](analyst-method-lifecycle.md) and require an independent closure checkpoint |
| Correct eligibility helper with no mandatory caller | The pure rule rejected stale policy/identity/replay states, but the public read path still returned the raw current pointer | Make the admitted read model the only publishable API; repository-search every bypass before closure |
| Semantic parse fails before supersession handling | A trusted rejected revision can return early while the stale prior projection remains current | Parse a safe control envelope first; then atomically publish the new candidate or invalidate the prior one |
| Same output treated as same command | Different EPS/P-E role bindings can share an evidence set and result, defeating an outcome-only lifecycle hash | Persist and fingerprint explicit semantic bindings and every transition coordinate |
| Mutation test changes the claimed field and membership | The role-binding test stayed green because the evidence-set hash changed, so it did not prove role IDs were identity-bearing | Hold every other byte constant and mutate exactly one semantic field; manually remove that field and require the test to turn red |
| Opaque run FP over mutable identity rows | `ORDER BY ... LIMIT 1` can select an arbitrary/old identity vintage and a hash alone cannot reconstruct the run | Persist exact immutable identity/share-basis references and supersession command fields |
| Read model resolves “current” identity with `LIMIT 1` | A valid ledger can contain multiple historical aliases/share bases, making lexical order choose another issuer or a pre-split candidate | Use an authoritative current coordinate or fail closed with an explicit ambiguity/stale reason; test the public dossier after restart |
| `ON CONFLICT DO UPDATE` on a “vintage” row | Historical run coordinates silently changed in place despite vintage IDs and fingerprints | Vintage writes are insert-or-identical-no-op; different content under the same key is a conflict and requires a new vintage ID |
| Current revision edge green, ancestor graph unchecked | An upstream cycle, conflicting predecessor, or foreign partition could survive while the descendant remained eligible | Reconstruct the entire reachable ancestry; require existence, one intent, partition consistency, and no revisited revision, with reopen corruption tests |
| “AMZN $5 disputed = OK” | Full SEC history put CapEx-trough years in the recent window; plain median FCFF margin collapsed run-rate; labeling disputed hid a real engine bug | Base margin = median of **non-negative** annual FCFF when ≥2 exist; scenarios keep full distribution; baseline fixture must include full drivers on trough years; never green-light sub-$50 AMZN-class as product success |
| Latest positive FCFF refused as missing drivers | SNDK FY2026 printed +$11.5B FCFF; the 4-year median stayed negative; UI said drivers were missing | When the latest aligned FCFF margin is positive, that year is the base (`latest_positive_aligned_annual`). Refuse only when the latest year is also non-positive. Copy filed statutory tax onto Yahoo years that lack `annualMarginalTaxRate`. Copy filed SEC interest onto Yahoo years that lack a coupon. Skip cash-paid tags. |
| Yahoo list DCF refused for missing tax | 336 SP500 names had OCF, CapEx, and revenue, but empty `annualMarginalTaxRate` | Attach the versioned domicile statutory rate (`DomicileTaxProxy`) from issuer country. Keep filing statutory first. Missing country stays unavailable. |
| Latest reported FCF blocked driver FCFF | Yahoo latest FCF ≤ 0 made source selection NotEligible before the driver engine ran (ORCL, BA, PCG class) | Keep LatestFcfNonPositive only when aligned OCF/CapEx/revenue years are short. Driver FCFF decides from the annual identities. |
| Net-cash name refused for a missing coupon | Snapshot debt > 0 with cash covering it, Yahoo interest empty, WACC still demanded k_d | If reported cash covers reported debt, a failed coupon is not-applicable. Material net debt still refuses. |
| Default “not financial ⇒ FCFF” | CI Healthcare Plans → absurd DCF; UI did not refuse | Closed-world `Unclassified` + reason in UI |
| One cash model on a factory-plus-lender filing | General Motors yield hook printed $464 from mixed factory and loan cash | `component-sotp/2`: value each part; add; ticker is not the rule. Only parents in machinery, auto, tools, or equipment host a captive. Credit Karma, Moody's product lines, and IT client verticals stay on FCFF. |
| Factory NOPAT minus plant spend | NOPAT is after depreciation; subtracting full CapEx double-counts plant | Factory FCFF = NOPAT + depreciation − sustaining CapEx |
| Weak absurd checks / quarantine-as-green | Suite green while MU-class OOM or many quarantines | Order-of-magnitude + business-class asserts; 20-slot fixture = **0** quarantine |
| Backend refuse, UI mute dash | User cannot tell model refused vs still loading | Surface `valuation_unavailable_reason` / i18n refuse copy |
| Backend DCF green, Detail still unavailable | COF returned valid residual income while the UI discarded it because operating `valuation_status` was null | Probe the active Tauri invoke over local CDP and assert the rendered Detail; typed residual income is independently publishable |
| Presenter tests cover dead code | The dedicated analyst-method presenter and cache-only endpoint were green but the mounted Quant Lens panel used a different backend section path | Repository-search the production import/call site and require a DOM-scoped native assertion on the exact lane selector |
| Rust `i64` serialized as JavaScript `number` | Exact fixed-point FEM values could round above `2^53−1`, while Rust overflow/parity tests stayed green | Cross IPC as decimal strings and format with `BigInt`; never detour through `f64`/`Number` |
| Required native/live gates relabeled optional | Builder evidence stopped at unit tests although the architecture required restart, DOM-native, Android, and one-process live `qa` proof | Closure gates come from the governing architecture; record actual commands/results before changing status |
| Whole-Detail text assertion | Mutation stayed green because Quant Lens echoed `$168.81` while the hero slot still said unavailable | Scope native regression assertions to `.price-summary .dcf-slot`, not the whole Detail panel |
| Attach UI without agent bridge / stale slot | DOM row-click + previous symbol text made live checklist “PASS” while Detail never changed | Require DEV `window.__DS_AGENT__`; `ds-ui open-detail` must exit non-zero if selection/slot not settled; `self-check` before claiming live QA green |
| business_class string mismatch in asserts | Checklist compared PascalCase to snake_case so class asserts never fired | Normalize class tokens (`financial_services` / `FinancialServices`) before asserting |
| Only automated tests | Live still shows stale cache or wrong label | Live checklist after model changes |
| Open Detail again after Back | Leftover → EXPD was slow a second time: Back wiped UI, `ensureDetailLoaded` hit SQLite and could retry DCF, leftover/dip boards rebuilt MACD on every snapshot | Keep a session paint for the last Detail; skip disk/network when memory is warm; memo leftover/dip boards by input fingerprint; clear hydration and live-DCF flags in `resetInMemoryLocked` |
| Profile switch leaves old Yahoo work running | Switch felt slow and the new Opportunities fill crawled: in-flight quote/chart calls finished, `Thread.sleep` on 429 blocked `Dispatchers.IO`, and an unregistered hydrate job could cancel the new refresh | Bump generation, register the switch job on that lock, skip fetch when the generation is stale, abort OkHttp on cancel, `delay` instead of `Thread.sleep`, one ViewModel select job |
| Append chart JSON to `raw_capture` on every refresh | Phone DB grew to 2.2 GB; warm start decoded every latest 10Y blob | Write candles only to `pricing_candle`; copy latest leftover JSON into that table before delete; do not decode charts at warm start |
| Cold-start full SP500 for every agent QA | Thousands of Yahoo requests; rate limits; wasted time | **QA = profile `qa` only** → Windows `npm run tauri:dev:qa`; Android `make android-run-qa`; reuse one process; one-shot checklist loads |
| Android QA on default `sp500` | 500+ tickers; same thrash as Windows full universe | `make android-run-qa` boots **`qa`**; never switch UI to sp500 for agent QA |
| `pm clear` / wipe app data for QA | Deletes the on-device SQLite (multi-GB warm store) | Install with the QA flag only. Membership switches to `qa`. The database stays |
| `tauri dev -- -- --profile qa` | Cargo steals `--profile` → compile error / full universe fallback | `npm run tauri:dev:qa` or `DS_UNIVERSE_PROFILE=qa`; binary `--universe qa` |
| “I’ll just open the normal app for QA” | Full universe + thrash restarts | Wrong. **QA is profile `qa`.** No silent default to `sp500` |
| One acquisition zeroes the whole growth window | Historical M&A made BSX/ADSK/AVGO-class estimates ignore later clean growth | Contaminate only Y−1→Y; require two clean recent transitions and a clean latest transition, otherwise zero growth explicitly |
| Analyst gap pill sits beside DCF with no source | A positive Street upside looked like it described a below-market DCF | Label the analyst relation and show DCF-vs-market independently |
| Naked `sum / n` over an annual series | One 5208% implied coupon inverted a whole cross-sectional credit fit; a plain mean of 19 annual returns reported restructuring years as return | `valuation_core::robust_mean` / `standardize` — never a hand-rolled average. See **Aggregation — no naked averages** in `AGENTS.md` |
| 3-sigma rule built on mean and standard deviation | Provably cannot fire at `n <= 10` (max score is `(n-1)/sqrt(n)`); the outlier inflates its own scale and hides | Median/MAD scores, which have 50% breakdown and no such ceiling |
| Cash-flow tag used as an income-statement equivalent | `InterestPaidNet` (interest *paid*) sat in the interest-**expense** qname list and gap-filled an accrual series year by year; it was one issuer's only source across nine years | Equivalence classes hold one statement's concept only; an issuer that files none reads **absent**, not a substitute from another statement |
| Lease-subset interest used as the coupon | `FinanceLeaseInterestExpense` is the finance-lease slice. Lowe's 2020-2022 had only that line (~$30M) while later years file ~$1.3B of net interest, so coverage looked like AAA (59 bps) | Drop the lease subset from the expense class. Keep the income-statement net lines. Use the magnitude when the issuer files the net as a negative |
| E&P well program classified as an acquisition | `PaymentsToAcquireOilAndGasPropertyAndEquipment` is the issuer CapEx line for EOG-class names. Treating it as property acquisition left only `OtherPropertyPlantAndEquipment` (~$0.5B) and invented a ~45% FCFF margin | The well program is a disjoint development component, summed with other plant. `PaymentsToAcquireOilAndGasProperty` (no equipment) stays acreage acquisition. Do not retune path knobs to hide a taxonomy miss |
| Contract listed software; Android summed only plant | `sec-driver-normalization/9` already named `PaymentsForSoftware` / `PaymentsToDevelopSoftware` as a disjoint development component (FIS $0.835B). Android kept plant+wells only, so DASH-class names understated CapEx | Sum software with plant. Drop software when the tangible tag is `PaymentsToAcquireProductiveAssets`. Keep software in `retainedQnames` or the sieve deletes it |
| A reader's filter left on the reader alone | Every companyfacts reader dropped quarters, non-10-K forms and dimensional rows **after** the parse, so the phone held 595 KB and parsed 4.6x the rows it used per company | Filter on the stream, in `SecCompanyFactsSieve`, and keep the reader's check as the second gate. The sieve is now the boundary of what exists: widening a reader means widening the sieve and bumping `COMPANY_FACTS_SIEVE_VERSION` |
| One client's sieve copied to the other | The desktop readers keep `frame`, `fy` and `accn` and accept `10-Q` and `8-K`; Android keeps none of them. A shared field set silently empties the shares count | Derive each field set from that client's own readers, and hold it with a parity test over a real companyfacts fixture |
| A pinned valuation number with no policy version | COF's residual income pin stayed at 16 881 cents while `0c897087` moved the answer to 17 881; three assertions in two files failed for twelve days and the red looked like background noise | Name `MODEL_POLICY_VERSION` next to the pin and re-pin in the commit that moves the policy. A gate that measures model quality is the exception: fix the model, never the number |
| A client that builds its own http client | `SecIssuerComponentClient` created its `OkHttpClient` in the constructor, so the streamed companyfacts sieve ran on a path no test could reach | Take the client as a defaulted constructor parameter. Hold a streamed path with `cannedHttpClient`, which sits under the client where the body is still a body |
| Recurring intangible cash treated as M&A or dropped | Comcast files `$2.0–3.3B` of `PaymentsToAcquireIntangibleAssets` every year next to PPE. That line is spectrum, software, and license cash. Dropping it overstated CMCSA FCFF | Sum `PaymentsToAcquireIntangibleAssets` with plant. Drop it on `PaymentsToAcquireProductiveAssets`. Keep `PaymentsToAcquireBusinesses` rejected. Fingerprint `/10` |
| Margin expanded to industry with no franchise | DASH (ROE below WACC) expanded to a 20% industry FCFF margin | Expand internet retail/content to the industry target only when excess ROE is positive. Path `valuation-path/4-no-expand-without-franchise` |
| Signal written by the engine, read by nothing | `fundamentalsSignals` was built, persisted and carried into the snapshot with no composable reading it. It hid the sector `§` marker **and** the share-count reading — one root cause, two symptoms, and only the first was being looked for | Grep the field name under `src/main` and name its consumer before calling the wave done. A claim about the user's screen that lives only in a data class is not shipped |
| Gate states a magnitude and no sign | Wave 0 required `abs(rho) >= 0.3` on two bucket pairs, passed on `+0.381` and `−0.367`, and never said both must run the same way. Half its premise failed under a green gate | Write the sign into the gate. A threshold that cannot fail on the population that would falsify it is not measuring anything |
| One-directional mutation round | Ten mutants each moved a fixture constant the same way and all died, reported as a full kill. Twelve mutants moving both ways found five constants pinned on one side only | Move every mutated constant in both directions; a `>` assert survives one of them by construction |
| `--rerun` written once for two tasks | `:core:test :app:testDebugUnitTest --rerun` returned `:core:test UP-TO-DATE` — green, never executed | One `--rerun` per task; read the task lines before believing a green run |
| Release falls back to the debug key | No keystore configured, so the release build type used the debug signing config and a bare `assembleRelease` exported it as a release APK. That key is on every machine that has ever built an app | Bare `packageRelease` refuses. `make android-release` is the release *build type*, not a signing identity: it passes `-PallowDebugSignedRelease=true` and warns. A real key is `make android-signing-bootstrap`. Never let a bare Gradle release downgrade its own trust in silence |
| Approved plan text not snapshotted before execution | The plan authorised one `sp500` run as a named exception to the `qa` rule, then was revised in place. Nothing could later prove the exception had been approved rather than assumed — an unprovable-not-authorized state, which is worse than either answer | Copy the approved plan to `plan.v0.md` under the session directory at approval, before the first builder spawn. Revisions become `plan.vN.md`; `v0` is never edited |
| Verifying a property no live QA can reach | Sector benchmarks need 5 members and the mandated `qa` universe's largest sector holds 4, so a device pass could never touch the changed path — and a re-QA was nearly ordered anyway | Check path reachability under the QA universe **before** arming a live stage. Unreachable live means prove it by test and say so; it never means defer the fix |
| SEC filing `fy` used as the period key | AAPL 2023–2025 comparatives in the 2025 10-K all keyed as 2025. Interest existed through 2023 and the recent window went empty | Align on period end (`asOfDate` / `periodEnd`). Do not write SEC `fy` into `fiscalYear`. `NonoperatingIncomeExpense` is not a coupon |
| Apple-class coupon read from Other income net | From FY2024 Apple stopped tagging `InterestExpense`, `InterestPaidNet`, and the Other-income breakdown. The FY2025 10-K face is Other income net $(321)m. The Debt note has CP 4.19% and term-debt rate ranges. Cash flow supplemental files tax paid only | Do not invent a coupon from `NonoperatingIncomeExpense` or a note rate range. Fill a hole only through `coupon-resolution/1` (own last rate or peer median) with a visible confidence band. A later filed tag replaces the estimate. Estimated coupons stay out of k_d (`debt-resolution/1`). `InterestPaid*` is not a filed coupon |
| Stated coupon or credit index used as issuer k_d | OpenFIGI tickers carry the coupon (AAPL 3.25). FRED ICE/BofA series are a market, not this issuer. Cheap old coupons understate WACC | k_d uses a current USD instrument yield (`issuer-market-yield/2`). The yield does not shrink the tax-year window. Then coverage synthetic, then the filed coupon over average debt. Empty when no issuer quote exists |
| Captive-finance issuer treated as a missing coupon | PCAR Yahoo interest is empty. The parent 10-K prints `FinancialServicesMember`. EFTS full-text of `"paccar Financial"` hit the parent 10-K, so the match dropped the hit. PACCAR Financial Corp CIK 0000731288 and Caterpillar Financial Services Corp CIK 0000764764 file their own 10-Ks. Snap-on Credit and HPEFS do not. | Search EFTS `entityName=$stem $arm` first, then full-text `q`. Load residual book from the sub companyfacts. Parent-segment revenue or EBIT is not book. Do not invent a coupon on captive cash. |
| Yahoo payout above 1 treated as missing retention | ARES and BX distribute more than GAAP earnings. `payoutRatio` 1.47 became `retentionBps = null` and residual income refused | Payout `≥ 1` is retention 0. Negative payout stays missing. |
| Yahoo quoteSummary 404 dropped a live equity | BK and SATS 404d quoteSummary with a valid crumb. The refresh wrote "No market data after retries" and never stored a row. FISV, FOX, and NWS sat behind them and were never asked. Dual-class FOX/NWS are not FOXA/NWSA. | On quoteSummary HTTP 404 only, scrape the quote HTML page. Do not scrape on 5xx. Do not copy Class A onto Class B. |
| Soft fan shipped as complete identity | Wide NVDA/META-class fans stayed `identityComplete` because soft still counted as complete | Width null or `> IDENTITY_USABLE_MAX_WIDTH_BPS` is incomplete (`UnusableIdentityFan`). Soft stays complete only at or below that cut |
| Aligned claimed from one-sided % | ACGL display vs price looked Aligned while official `differenceBps` was 2890 (Tension) | Stance and the displayed official gap use `ValuationDecisionPolicy.differenceBps` on identity base vs Street base. Never a one-sided percent versus price |
| Street mix sold as identity | A Street-weighted forecast cut APE by using Street to approximate Street | Keep Street as the scoreboard. Publish typed `NonHonest` implied knobs. Never hide the cheat inside honest inputs |
| `ape_nh` near 0 treated as a model win | One-knob inversion hits Street by construction | Publish implied bps, delta, and stretch. The signal is how far Street sits from honest, not the inverted price |
| Growth rate formed across a negative base | A loss narrowing printed as decline (−30 → −25 read −16.7%) and a loss-to-profit crossing printed −20 000 bps for a doubled profit; the garbage sample then refused Pulse on real turnarounds | Rates form only from adjacent positive-level pairs (`positiveLevelTransitions`); the Yahoo quarter rate is compared against profit-year transitions only |
| Adjacent survivors treated as adjacent years | A missing fiscal year made 2021→2023 print one "annual" +53.6% move; share-count and cycle-peak regimes read multi-year moves as annual | `areConsecutiveFiscalYears` gates every pair before any ratio; a gapped series refuses rather than misdates |
| EBITDA leverage scored on financials | Deposits/float sat in the debt line, so banks and insurers carried an industrial leverage vote (C's `Bal:+15` came from liquidity aggregates) | `FinancialClassPolicy` allowlist drops the whole leverage vote for `financial-services`; ROE/P/B keep ranking them; unclassified sectors keep today's rule |
| One fact family, two votes | FCF yield and cash conversion both re-read FCF, so cash-rich names got ~32 of 110 bucket points from one number | Conversion retires when the yield vote fired (`cashFlowYieldVoted`); it still speaks when only the sign voted |
| Conflict flag read a ramp sign near the band midpoint | Trend +6% vs Pulse +4% flagged "Pulse≠Trend" because the shared band's midpoint is +5%; two healthy growers looked like a quarrel | Flag on bps distance (`V4_GROWTH_CONFLICT_BPS = 1_000`), mutated in both directions against unit + contract cases |
| One resolver's sign rule imposed on every consumer | `resolve_book_value_per_share_cents` dropped a negative reading, which is right for price-to-book and residual income and wrong for return on invested capital; WYNN reports `-166` cents and $12.3 B of debt, so its capital base is $12.2 B, and both routes to a return on capital closed on the sign alone | Give the second consumer its own field (`book_value_per_share_cents_with_deficit`) and let the guard that protects the arithmetic (`invested <= 0`) do the refusing |
| A guard that repeats a check two lines below it | `through_cycle_return_on_capital_bps` refused on `book_value_per_share_cents > 0` above its own `invested <= 0` check, so it rejected rows the real guard would have accepted | When two guards sit in one function, ask which one states the arithmetic constraint; the other is a policy hiding in a safety check |
