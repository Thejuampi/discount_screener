## Profile speed experiment

Goal: minimize time to useful rows and complete coverage. Preserve the current S&P 500 path.
Keep one shared Yahoo request budget. Separate profiles must not bypass a provider hold.
Profile-specific behavior should describe work size, cache coverage, priorities, and measured sustainable rate.

| Order | Work | Acceptance evidence |
| --- | --- | --- |
| 1 | Fix R1 before rate changes. | No market universe request starts before the first profile refresh finishes. |
| 2 | Record endpoint calls, useful rows per second, refusals, wait time, and disk time. | One trace explains each pause by stage and provider. |
| 3 | Declare the current code as the neutral baseline. | Capture cold, warm, expired-cache, and forced-refresh results per profile. |
| 4 | Compare a burst plus sustained-rate policy against the current reactive policy. | Use the same payloads, quota model, and cache state for both variants. |
| 5 | Use one controlled recovery probe after a quota hold. | Recovery resumes useful work without a new refusal burst. |
| 6 | Prioritize book and visible-row demand within the shared budget. | A selected held name does not wait behind all bulk work. Provider holds still apply. |
| 7 | Check S&P 500 and Russell separately. | S&P 500 meets its unchanged budget. Russell improves complete coverage time and refusal count. |
| 8 | Repeat with restart and profile switch. | Fresh data survives restart. Old work stops. The new profile does not inherit old results. |

The offline matrix needs these cases:

- S&P 500 cold, warm, and forced refresh.
- Russell cold, mixed cache, and expired cache.
- A replenishable quota with no `Retry-After`.
- A concurrency limit, slow responses, and a long quota closure.
- Detail demand during bulk work.
- Profile switch during a hold and during a store write.
- A slow store and a bounded-memory assertion with the real market reader.

Measure first useful row, half coverage, full coverage, total calls, refusals, longest pause, and peak memory.
Measure UI response time separately from total network time.
Use endpoint requests as the work unit. A symbol can require several endpoint calls.
Do not select a fixed Russell delay from profile size alone.

Use offline provider doubles first. Current quota tests model a permanent refusal or a concurrency limit.
They do not model a large universe that consumes and regains a time-based quota.
Live non-QA profile experiments need explicit authorization under the standing project rule.
