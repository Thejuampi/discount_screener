- (insight) Chase changed CSV headers. Snapshot has no side. Blotter names the price Price USD.
- (decision by juan) A holdings snapshot is a full image. Anything out of the file must be removed.
- (decision) Name the file kind before any write. J.P. Morgan positions is holdings_snapshot. Chase transactions is trades_window. Coinbase, Schwab, and generic stay trades_ledger.
- (decision) Holdings snapshot uses unit cost and US thousands. PHYL quantity 1,273 is 1273. Price is unit cost 35.28, not market 34.61. Side is buy. Cash and QACDS rows drop.
- (decision) The panel warning names snapshot, load count, remove count, omitted symbols, and as-of. Confirm upserts listed symbols and deletes every current lot the file omits. Cancel writes nothing. window.confirm is not the surface. An empty keep set refuses and does not wipe the book.
- (decision) A Chase blotter merges onto the current book. Trades with trade_date > book_as_of change quantity and cost. Trades on or before as-of leave quantity and cost. Empty opened_at takes the earliest blotter buy. No current lots, or no as-of, refuses with a reason. The blotter never aggregates from zero.
- (decision) Chase Type maps to a closed set. Buy and Reinvest are buys. Sell is a sell. Quantity uses abs. Dividend, DBS, WDL, DBT, BNK, and Name Change skip. Unknown Type skips.
- (constraint) Detect order is Coinbase, Schwab, J.P. Morgan, Chase, generic. JPM and Chase dates are US MM/DD/YYYY. Generic dates stay Latin DD/MM/YYYY.
- (constraint) Book as-of lives in localStorage key ds_advisor_book_as_of. A sell that exceeds the lot skips that trade. The importer does not open a short. Refuse over invent.
- (constraint) No tax lots. Average cost only. No second account merge. No Android import. No schema change on portfolio_positions. No change to Coinbase, Schwab, or generic ledger apply.
- (assumption) The two files share one Self-Directed account. The 90-day blotter is a window, not the full history. Snapshot as-of and the newest blotter date can fall on the same day.
