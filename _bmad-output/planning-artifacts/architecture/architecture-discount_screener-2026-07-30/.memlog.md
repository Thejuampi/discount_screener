- (decision) AD-1: provider adapters own raw source acquisition; a canonical resolver owns period alignment, source precedence and provenance before model engines.
- (decision) AD-2: the resolver emits one typed ResolvedRateInputs contract consumed by both FCFF engines; no platform-specific default branch may replace it.
- (decision) AD-3: financial routing precedes rate resolution; FinancialServices invokes residual income only, OperatingNonFinancial invokes FCFF rate resolution.
- (decision) AD-4: unavailable is a first-class state that clears stale FCFF, contributes no synthetic score, and projects reason codes to Detail and Quant Lens.
- (decision) AD-5: public parity compares fixed-point integer outputs and provenance exactly; comparator failure blocks validation.
- (decision) AD-6: caches include engine, policy, source and resolver fingerprints; policy or selected-source changes invalidate prior analysis.
- (decision) AD-7: live QA uses one long-lived qa profile with at most twenty symbols; no full-universe startup is permitted.
